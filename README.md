A single quiet line for the make.fun bounty **One Line of Earned Pride** (slug `u-mang-one-line-of-earned-pride-a0138557`).

`main.ts` writes one entry to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`). The entry is a concrete, understated scene: after eleven winters of mending nets by lamplight, Tomas stands on a grey pier at dawn and watches his granddaughter haul her first catch in alone, his hands in his pockets — a long effort finally landing, with the pride shown only by his restraint.

Run it with:

```sh
node main.ts
```
